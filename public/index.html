Methodology

Benchmarks & API $/task come from Artificial Analysis, including the overall Intelligence Index, domain capability scores, individual tests, and average API cost per benchmark task.

Plan subsidies come primarily from upstream Real API Pricing and first-party published credit pools (GitHub Copilot, Ollama Cloud), with secondary backfill from Priors for per-effort sub-tests and unmeasured recent releases. Subsidies measure how many dollars of API usage a subscription provides per $1 of monthly fee at full usage.

Calculations:
Real $/task = API $/task ÷ plan subsidy
API 3:1 blended $/1M = (3 × input $/1M + 1 × output $/1M) ÷ 4
Real $/1M tokens = API 3:1 blended $/1M ÷ plan subsidy
Tasks/mo (or Mtok/mo) = monthly plan fee ÷ real cost

Per-task cost is usually the fairer cross-model comparison since it reflects each model's actual reasoning, output length, and caching on benchmarks; Per 1M tokens applies the plan subsidy to Artificial Analysis's standard 3:1 input:output blended rate. Legacy and off-peak plans are hidden by default, and pay-as-you-go API prices can be toggled on in Settings. Data refreshes automatically every 6 hours.
