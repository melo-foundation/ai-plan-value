Methodology

Intelligence & API $/task come from Artificial Analysis, which measures each model's Intelligence Index score and average API cost per benchmark task.

Plan subsidies come from Real API Pricing and Priors, measuring how many dollars of API usage a subscription provides per $1 of monthly fee at full usage. Some recently released models use preliminary user reports or prior-generation quota estimates until measured directly.

Calculations:
Real $/task = API $/task ÷ plan subsidy
Tasks/mo = monthly plan fee ÷ real $/task

Pay-as-you-go API prices are hidden by default and can be toggled on with "Include API". Data refreshes automatically every 6 hours.
