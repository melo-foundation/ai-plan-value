Methodology

Data sources
  • Benchmarks & specs: Artificial Analysis (Intelligence Index, domains, tests, API $/task), OpenRouter (context windows, open weights, supported efforts, domain backfill), and ARC Prize (ARC-AGI-2 fallback for unmeasured effort ratios).
  • Plan subsidies: Real API Pricing, published credit pools (GitHub Copilot, Ollama Cloud, Kilo Pass), and Priors backfill.
Calculations
Real $/task = API $/task ÷ plan subsidy
Real $/1M tokens = API 3:1 blended $/1M ÷ plan subsidy
Tasks/mo (or Mtok/mo) = monthly fee ÷ real cost

Subsidy = API dollars included per $1 of monthly fee at full usage. Setting a Monthly API usage in Settings computes actual break-even cost (counting unused quota or API overage past a plan's cap).

Footnotes Accuracy report
*
Estimated subsidy: preliminary user report or prior-generation quota carryover.
†
Interpolated effort: missing reasoning level bracketed between a lower and higher measured effort on the same model (typical error ~±1.1 pts / ±12% $/task).
‡
Extrapolated effort: unmeasured reasoning level estimated from measured effort steps on other models in the same family, or ARC-AGI-2 effort ratios where a family lacks multi-effort AA data (typical error ~±2–3.5 pts / ±14–26% $/task).

Per-task cost reflects actual reasoning, output length, and caching; Per 1M tokens uses Artificial Analysis's 3:1 input:output blended rate. Legacy and off-peak plans are hidden by default. Refreshes automatically every 6 hours.
