Methodology

Data sources
  • Benchmarks & specs: Artificial Analysis (Intelligence Index, domains, tests, API $/task), OpenRouter (context windows, open weights, supported efforts, domain backfill), ARC Prize (ARC-AGI-2 fallback for unmeasured effort ratios), Artificial Analysis Coding Agents (Coding Agent Index, agent $/task), CursorBench ($/task), and T3 Code ($/turn from user telemetry), both via Priors.
  • Plan subsidies: Real API Pricing, published credit pools (GitHub Copilot, Ollama Cloud, Kilo Pass), and Priors backfill.
Calculations
Real $/task = API $/task of the selected cost metric ÷ plan subsidy
Coding Agent = AA agent run for the plan's agent; open endpoints and APIs use the model's default agent
Real $/1M tokens = API 3:1 blended $/1M ÷ plan subsidy
Real $/turn = mean API-list cost of a real T3 Code turn (30 days of user telemetry) ÷ plan subsidy
CursorBench = CursorBench score and $/task for the model and reasoning level
Min benchmark and Cost metric are independent: any score filter pairs with any cost
Tasks/mo (or Mtok/mo) = monthly fee ÷ real cost

Subsidy = API dollars included per $1 of monthly fee at full usage.

Footnotes Accuracy report

Estimated subsidy: preliminary user report or prior-generation quota carryover.
●
High confidence: missing reasoning level bracketed between a lower and higher measured effort on the same model, or one effort step from a measured effort using same-family step sizes; agent score from the same model and agent measured at another effort, shifted by the Intelligence Index gap.
◐
Medium confidence: unmeasured reasoning level two effort steps from a measured effort, or estimated from ARC-AGI-2 effort ratios where a family lacks multi-effort AA data; agent score copied from another agent's run of the same model, or fitted on Terminal-Bench 4.0.
○
Low confidence: unmeasured reasoning level three or more effort steps from a measured effort; agent score fitted on Terminal-Bench 4.0 below the range of measured models, or built on a low-confidence effort estimate.
