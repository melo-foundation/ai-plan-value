Methodology

Real cost

What a piece of work actually costs you on a plan, if you use the plan's whole quota.

Real cost = API price of the work ÷ plan subsidy
Subsidy = dollars of API usage the plan's quota covers per $1 you pay. 50× means a $20 plan covers $1,000 of API usage.
Tasks/mo = monthly fee ÷ real cost
Cost metrics
MetricThe unit of work being priced
AA Intelligence taskOne task from Artificial Analysis's general benchmark (reasoning, knowledge, coding), run on the bare model
AA Coding Agent taskOne coding task run inside the plan's own agent, such as Claude Code or Codex (AA Coding Agents)
CursorBench taskOne task from Cursor's coding benchmark
T3 Code turnOne real back-and-forth turn, averaged over 30 days of T3 Code users. Turn length differs between agents, so compare models within one agent. On Claude plans a T3 turn counts about 2.1× against the 5-hour limit, because T3 Code connects through the Agent SDK.
1M tokensA million tokens at list price, 3 parts input to 1 part output

How the trust levels are calculated
σ = sd of ln(real cost); σ² = Σ step σ² over subsidy chain, token mix and cost metric
Range = real cost × e±1.28σ
Level = worst of cost σ, score error (±1.5 / 3 / 5 pts) and the upstream grade
